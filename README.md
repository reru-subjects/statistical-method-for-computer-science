## วิธีใช้เอกสาร

1. เปิดหัวข้อประจำสัปดาห์และอ่านใบความรู้พร้อมตัวอย่างการคำนวณ
2. ทำใบงานตามขั้นตอน โดยใช้ข้อมูลและเงื่อนไขที่กำหนดในแต่ละใบงาน
3. ใช้ Python ใน Google Colab หรือ Jupyter Notebook สำหรับกิจกรรมที่ต้องเขียนโปรแกรม ติดตั้งไลบรารีตามที่ใบงานระบุ เช่น pandas, NumPy, SciPy หรือ scikit-learn
4. แนบขั้นตอน ผลลัพธ์ หน่วย และคำอธิบายด้วยภาษาของตนเองตามรายการที่ระบุในใบงาน แล้วส่งตามที่ผู้สอนแจ้งใน Google Classroom
